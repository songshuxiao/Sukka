# Sukka

个人 Typecho 主题，移植自Hexo主题 [Sukka](https://blog.skk.moe/)  的设计

## 环境要求

- Typecho 1.3.0+
- PHP 8.0+（推荐 PHP 8.4）

## 功能特性

- 响应式设计，适配桌面和移动端
- 暗色/明亮模式切换（支持手动切换 + 跟随系统）
- 文章目录（TOC）自动生成
- 代码高亮（基于 highlight.js，支持 190+ 语言）
- 代码一键复制
- AJAX 评论提交
- 搜索功能（弹窗式搜索）
- 打赏功能（支持支付宝/微信二维码）
- 图片懒加载 + 点击放大
- 文章字数统计 + 阅读时间估算
- 上下篇文章导航
- 文章版权声明
- 文章过期提醒（超过 30 天的文章显示提醒）
- 回到顶部按钮
- 侧边栏博主信息、最新文章、分类、标签云

## 主题配置

在 Typecho 后台 → 控制台 → 外观 → Sukka 中可配置：

| 配置项 | 说明 |
|--------|------|
| 站点标识文字 | 导航栏左侧显示的文字 |
| 博主昵称 | 侧边栏显示的博主名称 |
| 博主描述 | 侧边栏显示的一句话描述 |
| 博主头像地址 | 留空则使用主题默认头像 |
| 支付宝打赏二维码 | 文章页打赏弹窗中显示 |
| 微信打赏二维码 | 文章页打赏弹窗中显示 |
| 打赏引导文案 | 打赏按钮上方的文字 |
| ICP 备案号 | 底部显示的备案信息 |
| 公安备案号 | 底部显示的公安备案信息 |
| 启用代码高亮 | 是否启用 highlight.js 代码高亮 |
| 随机缩略图 CDN | 文章无缩略图时使用的随机图片地址 |

## 文章自定义字段

在文章编辑页面可设置：

| 字段 | 说明 |
|------|------|
| img | 文章缩略图地址，留空则使用随机图片 |
